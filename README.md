# Anthony Lall Portfolio

This is my portfolio website. Thank you for visiting.

## Website Guide

The homepage introduces my work, background, and selected projects.

- `Work` opens the project gallery.
- `About` shares my background, skills, and experience.
- `Resume` opens an in-page preview with a download link.
- `GitHub` links to the source repository.

## Local Run

Open `index.html` directly in a browser, or serve this folder with any static file server.

No build step, framework, or package install is required.
